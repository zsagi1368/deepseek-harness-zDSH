## Branch status

`our/v2` is the DSH governance-enhancement branch, rebuilt directly on official `0.1.1-rc.2` (`upstream/master` at `b150a551b8`). Official files stay byte-identical to upstream unless an entry below says otherwise, so the authoritative delta is always the committed summary in `docs/dsh/diff-baseline.txt`, regenerated by `scripts/diff-with-official.mjs`.

The headline capability — plugin governance exposed through a host gateway service — is owned by the [plugin governance gateway Agent Note](../../.agents/notes/implemented/feature/2026-08-23-plugin-governance-gateway.md); product orientation starts from the root [README](../../README.md).
